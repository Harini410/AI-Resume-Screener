
# 📄 AI Resume Screener  

An **AI-powered web application** that screens resumes against job descriptions and provides a **match score**.  
The system uses **semantic similarity, embeddings, and TensorFlow.js** to analyze resumes and job postings, helping recruiters and applicants quickly assess compatibility.  

🔗 **[Live Demo](https://v0-ai-resume-screener-smoky.vercel.app/)**  
💻 **[GitHub Repository](https://github.com/Harini410/AI-Resume-Screener)**  

---

## 📖 Project Overview  

Recruitment often involves manually reviewing hundreds of resumes, which is **time-consuming and error-prone**.  
This project automates the process by using **AI-powered semantic analysis** to compare resumes with job descriptions and compute a **compatibility score**.  

The application demonstrates my skills in:  
- **Natural Language Processing (NLP)**  
- **Semantic similarity & embeddings**  
- **Full-stack AI web development**  
- **Deployment of AI apps on Vercel**  

---

## ✨ Features  

- 🤖 **AI-Powered Screening** – Analyzes resumes against job descriptions.  
- 📊 **Match Score** – Provides a compatibility percentage based on semantic similarity.  
- 🔍 **Semantic Embeddings** – Uses advanced NLP embeddings for contextual understanding.  
- ⚡ **Real-Time Analysis** – Instantly evaluates resume-job fit.  
- 🌐 **Deployed on Vercel** – Live, accessible demo.

## 🛠️ Tech Stack  

- **Language:** JavaScript

## ⚙️ Installation & Setup  

Follow these steps to run the project locally.  

### 1. Clone the Repository  
```bash
git clone https://github.com/Harini410/AI-Resume-Screener.git
cd AI-Resume-Screener
````

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

By default, the app will run at: `http://localhost:3000/`

---

## 🚀 Usage

1. Open the application in your browser.
2. Upload or paste a **resume**.
3. Enter or paste the **job description**.
4. Click **"Analyze"** to get a **match score**.
5. View the compatibility percentage and insights.
